Troubleshooting

Common problems

The app won’t open or says the developer can’t be verified

Go to System Settings › Privacy & Security and click “Open Anyway” for ModelPC VM. Make sure you’ve moved the app to the Applications folder.

A virtual machine won’t start

Check that your Mac has enough free memory and disk space. Lower the vCPU and memory assigned to the machine and try again; if the problem persists, restart the app.

No internet inside the virtual machine

Check that NAT mode is selected in the machine’s network settings and restart the machine. If a VPN or firewall is active on your Mac, turn it off temporarily and try again.

The ISO file won’t boot

Apple Silicon Macs need arm64 (aarch64) ISO images; x86_64 images won’t work. The file may also be incomplete — try downloading it again.

The virtual machine is slow

Assign fewer vCPUs than your Mac has cores, close apps you aren’t using, and keep at least 15% of your disk free. You can monitor resource usage in the Dashboard.

FAQ

Questions you may have

Which Macs does ModelPC VM run on?

It runs natively on Apple Silicon (M series) Macs. A recent version of macOS is recommended.

Which systems can I install in a virtual machine?

You can install arm64 Linux distributions — Ubuntu in particular — from an ISO image. You can also browse ready-made images in the ISO Images section.

Is my computer powerful enough?

At least 8 GB of RAM is enough. The Dashboard shows your host’s CPU, memory and disk usage, so you can balance resources easily.

What is a snapshot?

It is a saved state of the virtual machine at a given moment. If something goes wrong, you can restore the machine to it in seconds.

How do I get updates?

Use “Check for Updates” in the bottom-left corner of the app to find the new version and install it with one click.
