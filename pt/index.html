Perguntas frequentes

Suas dúvidas

Em quais Macs o ModelPC VM funciona?

Ele roda nativamente em Macs com Apple Silicon (série M). Recomenda-se uma versão recente do macOS.

Quais sistemas posso instalar em uma máquina virtual?

Você pode instalar distribuições Linux arm64 — principalmente o Ubuntu — a partir de uma imagem ISO. Na seção Imagens ISO também há imagens prontas.

Meu computador é potente o bastante?

8 GB de RAM já bastam. O Painel mostra o uso de CPU, memória e disco do seu Mac, para você distribuir os recursos com facilidade.

O que é um snapshot?

É o estado salvo da máquina virtual em um determinado momento. Se algo der errado, você a restaura em segundos.

Como recebo atualizações?

Use “Verificar atualizações”, no canto inferior esquerdo do app, para encontrar a nova versão e instalá-la com um clique.
